# Media Assist

Three modules that show editors what a site's image styles do to their
pictures: labels on rendered images, a crop summary and preview on image
media items, and Shape and Size controls in the CKEditor media balloon.

    drush en media_assist_crop media_assist_embed

The documentation is in `docs/`, starting at `docs/index.md`, and is built
with MkDocs from `mkdocs.yml`.
